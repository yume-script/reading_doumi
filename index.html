독서메이트

우측 하단에 떠 있는 캐릭터를 클릭하면 채팅으로 책을 추천받을 수 있어요.

마스코트는 이 탭을 최초로 연 순간 화면에 나타나서, 이후 다른 메뉴로 이동해도 계속 떠 있어요 (단, 브라우저를 새로고침하면 이 탭을 다시 한 번 열어야 다시 나타나요).

LLM API Key / 모델 / 캐릭터 이름·이미지는 환경설정 > 플러그인 > 독서메이트에서 설정하세요.

채팅창에 /완독 책 제목, /읽는중 책 제목, /읽을예정 책 제목, /상태, /랜덤, /통계, /시리즈 이름 같은 명령도 입력해보세요.

다른 플러그인 연동: /외부검색 책 제목(unified_book으로 서재 밖 검색), /퀴즈(책표지 퀴즈 탭 안내)도 지원해요.

책과 무관한 잡담용으로 /날씨 지역과 /주식 종목명도 지원해요 (둘 다 네이버 정보를 이용해서 별도 API 키가 필요 없어요).

그 외에도 /환율 통화, /로또, /코인 이름, /명언, /운세 명령을 지원하고, 답변 내용에 따라 아바타가 잠깐 다른 표정(🎉/😥)으로 바뀌었다가 원래 모습으로 돌아와요.
